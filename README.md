# MX Station Player v2.3 — Медиапортал для Media Station X & Smart TV

Интерактивный Smart TV портал на **Python (Flask)**, созданный специально для телевизоров (Samsung Tizen, LG webOS, Android TV, Fire TV, Apple TV) через оболочку **Media Station X (MSX)**.

---

## 📋 Главное меню (4 основных раздела)

Боковая панель включает ровно 4 раздела, каждый со своей уникальной 4K заставкой:

1. 📊 **Виджеты** (Фон: *Космическая Аврора 4K*)
   - Полупрозрачные стеклянные виджеты времени, календаря и планировщика с эффектом размытия (`backdrop-filter: blur`).
   - Настоящие тикающие стрелочные аналоговые часы, неоновые цифровые часы с секундами и минималистичные часы.
   - Кнопка **«Заставка 4K»** для мгновенного включения скринсейвера с пульта.
   - Кнопка **«Настройки виджетов»** для быстрого перехода к настройке.

2. 🚀 **Программы** (Фон: *Неоновый Киберпанк 4K*)
   - Плиточный каталог приложений (Lampa, YouTube MSX, IPTV, ForkPlayer, Lo-Fi Radio и др.).
   - Кнопка **«+ Добавить программу»** для перехода в управление ярлыками.
   - Запуск приложений во встроенном полноэкранном контейнере с возможностью мгновенного возврата по кнопке «Назад».

3. ⚙️ **Настройки** (Фон: *Горный Закат 4K*)
   - **Настройки виджетов**: выбор, какие виджеты отображать (Цифровые часы, Минимал, Аналоговые со стрелками, Календарь-сетка, Компактная дата, Планировщик ТВ), выбор их расположения (Посередине, Слева, Справа, Сверху, Снизу) и регулировка размытия стекла (14px, 25px, 38px).
   - **Настройки программ**: добавление новых приложений по URL, быстрый каталог популярных сервисов (Deeplex, Vplay, HDRezka, Kinopub, Twitch) и удаление ярлыков.
   - **Настройка заставки (Скринсейвер)**: ручной запуск, выбор картинок 4K (Космос, Киберпанк, Горы, Океан, Камин) или слайд-шоу всех фото, выбор таймаута бездействия (1, 2, 5, 10 минут).

4. ℹ️ **О приложении** (Фон: *Ночной Горизонт 4K*)
   - Информация о хосте, версии и навигации с пульта.

## 🔙 Навигация с пульта TV и кнопка «Назад» (Return / Back)

Решена главная проблема внешних сайтов на Smart TV, когда при переходе на сторонний сайт пульт переставал возвращать обратно:

- **Бесшовный возврат из приложений**: При запуске программы (Lampa, ForkPlayer и др.) сайт открывается внутри безопасного контейнера с верхней панелью управления:
  - Кнопка **`[ ← Назад в MX Portal (ESC / BACK) ]`** всегда доступна для клика пультом.
  - Нажатие аппаратной кнопки **«Назад / Return»** на пульте мгновенно закрывает сайт и возвращает вас ровно туда, откуда вы его открыли.
- **Поддержка всех пультов Smart TV**:
  - **Samsung Smart TV (Tizen)**: `VK_BACK` (код `10009`), аппаратное событие `tizenhwkey`.
  - **LG Smart TV (webOS)**: `VK_BACK` (код `461`).
  - **Android TV / Google TV**: `KEYCODE_BACK` (код `4`).
  - **Клавиатуры / аэромыши**: `Escape` (код `27`), `Backspace` (код `8`).
  - **Browser History**: перехват системного события `popstate`.
- **Иерархия возврата**:
  1. Если открыт сторонний сайт/приложение → закрывает его и возвращает в список программ.
  2. Если активна заставка → выходит из заставки.
  3. Если открыты «Настройки» или «О приложении» → возвращает на домашний экран «Виджеты».
  4. Для выхода из самого портала обратно в Media Station X предусмотрена кнопка **«Выход в MSX»** (`http://msx.benzac.de/exit.html`).

## 📺 Настройка на Smart TV

### 1. Подключение портала (Start Parameter)
В MSX на телевизоре откройте:  
`Settings` → `Start Parameter` → `Setup`

Введите адрес вашего хоста:
```text
<ВАШ_ПРОЕКТ>.vercel.app
```
*(Media Station X автоматически запросит `/msx/start.json` и запустит полноэкранный HTML5-портал через действие `link:`)*.

### 2. Подключение штатной заставки Media Station X
В MSX откройте:  
`Settings` → `Screensaver` (или `Настройки` → `Заставка`)

Укажите адрес плейлиста заставки:
```text
https://<ВАШ_ПРОЕКТ>.vercel.app/screensaver.json
```
Установите время бездействия (например, 2 или 5 минут).
