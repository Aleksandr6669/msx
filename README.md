# MX Station Player v2.2 — Smart TV HTML5 Портал для Media Station X

Медиапортал, полностью оптимизированный для запуска на **Smart TV (Samsung Tizen, LG webOS, Android TV, Apple TV)** внутри оболочки **Media Station X**.

---

## 💡 Почему теперь открывается HTML5-приложение на ТВ:
Встроенный парсер Media Station X для чистого JSON не умеет в реальном времени отрисовывать тикающие секунды, анимированные стрелки аналоговых часов, расчет дней календаря и интерактивные формы добавления приложений.
Поэтому теперь при вводе вашего адреса в **Start Parameter** Media Station X автоматически открывает нативное полноэкранное веб-приложение (`link:{SERVER}/`):
- **Никаких ошибок загрузки JSON** — всё работает гладко через веб-движок Smart TV.
- **Реальные тикающие часы** (цифровые, модерн, аналоговые со стрелками).
- **Реальный интерактивный календарь** с подсветкой сегодняшнего дня.
- **Полноценное управление программами**: можно прямо с пульта на ТВ вписать адрес любого приложения, и оно появится в сетке!
- **Автоматическая заставка (скринсейвер)** при бездействии пульта или по кнопке.

## 📋 Структура интерфейса (4 вкладки)

У каждого раздела — свой уникальный 4K фон:

1. 📊 **Виджеты** (Фон: *Космическая Аврора 4K*)
   - Цифровые неон-часы, аналоговые стрелочные часы, сетка календаря, расписание.
   - Кнопка «Настройки виджетов» и кнопка «Заставка 4K».
2. 🚀 **Программы** (Фон: *Неоновый Киберпанк 4K*)
   - Сетка плиток приложений (Lampa, YouTube MSX, ForkPlayer, IPTV, Lo-Fi Radio).
   - Кнопка «+ Добавить программу» для добавления собственных ярлыков.
3. ⚙️ **Настройки** (Фон: *Горный Закат 4K*)
   - **Настройки виджетов**: включение/выключение нужных блоков, позиция (центр, лево, право, верх, низ), сила блюра.
   - **Настройки программ**: добавление по URL, каталог быстрого добавления в 1 клик, удаление ярлыков.
   - **Настройка заставки**: немедленный старт, выбор темы заставки, настройка таймаута автозапуска (1 мин, 2 мин, 5 мин, выкл).
4. ℹ️ **О приложении** (Фон: *Ночной Горизонт 4K*)
   - Хост сервера, информация о системе и навигации.

## 📺 Подключение на Smart TV

1. **Вход в приложение (Start Parameter)**:
   В приложении **Media Station X** на ТВ откройте:  
   `Settings` → `Start Parameter` → `Setup`

   Введите **только ваш адрес хоста**:
   ```text
   <ВАШ_ПРОЕКТ>.vercel.app
   ```
   *(MSX сама запросит `/msx/start.json` и сразу откроет приложение в полноэкранном режиме без ошибок!)*

2. **Для штатной заставки в настройках MSX (по желанию)**:
   В `Settings → Screensaver` укажите:
   ```text
   https://<ВАШ_ПРОЕКТ>.vercel.app/screensaver.json
   ```
