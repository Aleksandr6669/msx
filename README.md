# MX Station Player — Сервер для Media Station X & MX Player

Приложение на Python (Flask) для создания интерактивного медиапортала на телевизорах Smart TV (Samsung Tizen, LG webOS, Android TV, Fire TV, Apple TV) через оболочку **Media Station X** с поддержкой плееров **MX Player** / встроенного TV-плеера.

## Возможности
- **Боковая панель (Sidebar Navigation)**: разделы «Главная», «Фильмы 4K», «Сериалы», «ТВ Каналы», «Музыка & Радио», «Заставка & Релакс», «Настройки».
- **Иконки и постеры**: Material Design иконки, высококачественные фоновые обои и постеры с бейджами (4K, LIVE, ХИТ).
- **4K Заставка (Screensaver / Ambient Lounge)**:
  - Живые видеозаставки с камином, космической авророй, неоновым дождливым городом и морским прибоем.
  - Режим слайд-шоу с автоматической сменой 4K фонов.
  - Полноэкранная интерактивная заставка с часами, датой и фоновой музыкой для браузера/ТВ (`/screensaver`).
- **ТВ Симулятор (Web Dashboard)**: при открытии с ПК или смартфона доступен предпросмотр интерфейса пульта и каталога.
- **Полная поддержка CORS**: бесшовное воспроизведение и навигация на любых моделях телевизоров.

## Структура проекта
```text
├── app.py                 # Главный Flask-сервер и MSX JSON API
├── requirements.txt       # Зависимости (Flask, Flask-CORS)
├── templates/
│   ├── index.html         # Веб-панель управления и ТВ-симулятор
│   └── screensaver.html   # Полноэкранная космическая 4K заставка с часами
└── static/
    ├── css/style.css      # Стили для боковой панели, сетки карточек и неона
    ├── js/app.js          # Интерактивная логика симулятора
    └── images/logo.svg    # Векторный логотип MX Station
```

## Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python app.py
```
Сервер запустится на порту `5000` и будет доступен в вашей локальной сети по адресу:
`http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/`

### 3. Подключение на Smart TV
1. Установите и запустите приложение **Media Station X** на телевизоре или ТВ-приставке.
2. Перейдите в меню: **Settings → Start Parameter → Setup**.
3. Введите адрес:
   ```text
   http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/start.json
   ```
4. Подтвердите выбор. Медиапортал с боковым меню, постерами и заставками загрузится автоматически.
