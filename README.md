# MX Station Player — Нативный медиапортал для Media Station X

Приложение на **Python (Flask)**, созданное **исключительно для работы внутри оболочки Media Station X (MSX)** на Smart TV (Samsung Tizen, LG webOS, Android TV, Fire TV, Apple TV). 

Никакого обычного веб-сайта — интерфейс полностью формируется и управляется нативно через JSON API стандарта Media Station X, на пульте ТВ.

---

## 🎯 Архитектура запуска (Start Parameter & Подпапка)

1. **Единственный адрес в подпапке `/msx/` — это `/msx/start.json`**:
   - По официальному стандарту Media Station X, когда вы вводите в поле **Start Parameter → Setup** просто имя вашего сервера (`<ВАШ_ПРОЕКТ>.vercel.app` или IP `192.168.1.50:5000`), приложение MSX **автоматически делает запрос к `https://<СЕРВЕР>/msx/start.json`**.
   - Внутри `/msx/start.json` прописан редирект в корневое меню:  
     `"parameter": "menu:https://<СЕРВЕР>/menu.json"`.

2. **Все остальные файлы и разделы находятся в корне**:
   - `/menu.json` — главное боковое меню (навигация по категориям);
   - `/screensaver.json` — штатная 4K заставка для функции **Настройки → Заставка** в MSX;
   - `/content/widgets.json` — интерактивные полупрозрачные виджеты часов и календаря;
   - `/content/settings_clock.json` — переключение стилей часов пультом на ТВ;
   - `/content/settings_cal.json` — переключение стилей календаря;
   - `/content/settings_pos.json` — выбор расположения виджетов (центр, слева, справа, сверху, снизу);
   - `/content/settings_bg.json` — галерея 4K фонов для моментальной смены обоев на ТВ;
   - `/content/movies.json`, `/content/tv.json` — каталоги фильмов и ТВ-каналов.

## 📺 Настройка на телевизоре (всего 2 шага)

### 1. Подключение портала (Start Parameter)
В приложении **Media Station X** на ТВ откройте:  
`Settings` → `Start Parameter` → `Setup`

Введите **просто ваш адрес** (без указания файлов):
```text
<ВАШ_ПРОЕКТ>.vercel.app
```
*(MSX сама автоматически подтянет `/msx/start.json` и сразу перенаправит в главное меню `/menu.json`)*.

### 2. Подключение штатной заставки Media Station X
В приложении **Media Station X** откройте:  
`Settings` → `Screensaver` (или `Настройки` → `Заставка`)

Укажите адрес плейлиста заставки:
```text
https://<ВАШ_ПРОЕКТ>.vercel.app/screensaver.json
```
Установите время бездействия (например, 2 или 5 минут). При простое пульта телевизор будет автоматически включать заставку 4K со сменяющимися пейзажами.

## 🧩 Управление виджетами и оформлением с пульта ТВ

Все настройки происходят прямо на экране телевизора без необходимости открывать браузер:

1. **Стили часов (Раздел «Стиль часов» в меню)**:
   - *Цифровые Неон (Digital)* — часы, минуты, секунды и дата;
   - *Минимал Модерн (Modern)* — утонченный стиль с крупным днем недели;
   - *Аналоговые со стрелками (Analog)* — круглый циферблат Chrono;
   - *Оба стиля часов (Both)* — цифровые и стрелочные часы одновременно.

2. **Стили календаря (Раздел «Стиль календаря» в меню)**:
   - *Сетка месяца (Grid)* — дни текущего месяца с подсветкой сегодня;
   - *Компактная дата (Compact)* — крупный день и статус;
   - *Планировщик ТВ (Events)* — расписание телепрограмм и премьер.

3. **Расположение виджетов (Раздел «Позиция виджетов»)**:
   - *Посередине (Center)*;
   - *Слева (Left)*;
   - *Справа (Right)*;
   - *Сверху (Top)*;
   - *Снизу (Bottom)*.

4. **Выбор заднего фона (Раздел «Выбор фона 4K»)**:
   - Карточки с предпросмотром 4K фонов (Космос, Киберпанк, Горы, Океан, Камин). При нажатии OK фон сразу применяется к интерфейсу.
