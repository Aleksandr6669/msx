# MX Station Player v2.0 — Медиапортал для Media Station X

Приложение на **Python (Flask)**, созданное специально для телевизоров Smart TV через оболочку **Media Station X (MSX)**.

---

## 📋 Главное меню (4 основных раздела)

Боковая панель включает ровно 4 раздела, каждый со своей уникальной 4K заставкой:

1. 📊 **Виджеты** (Фон: *Космическая Аврора 4K*)
   - Полупрозрачные стеклянные виджеты времени, календаря и статуса с эффектом размытия (`msx-glass`).
   - Кнопка **«🌙 Запустить заставку сейчас»** для мгновенного включения скринсейвера с пульта.
   - Кнопка **«⚙ Настройки виджетов и фона»** для быстрой кастомизации.

2. 🚀 **Программы** (Фон: *Неоновый Киберпанк 4K*)
   - Плиточный каталог приложений (Lampa, YouTube MSX, IPTV, ForkPlayer, Lo-Fi Radio и др.).
   - Кнопка **«+ Добавить программу»** для перехода в управление ярлыками.
   - Прямой запуск потоков в MX Player или внутреннем плеере.

3. ⚙️ **Настройки** (Фон: *Горный Закат 4K*)
   - **Настройки виджетов**: выбор, какие виджеты отображать (Цифровые часы, Минимал, Аналоговые со стрелками, Календарь-сетка, Компактная дата, Планировщик ТВ) и выбор их расположения (Посередине, Слева, Справа, Сверху, Снизу).
   - **Настройки программ**: добавление новых приложений по URL через экранную клавиатуру MSX, быстрый каталог популярных сервисов (Deeplex, Vplay, HDRezka, Kinopub, Twitch) и удаление ярлыков.
   - **Настройка заставки (Скринсейвер)**: кнопка мгновенного запуска, выбор картинки (Космос, Киберпанк, Горы, Океан, Камин) или режима слайд-шоу всех фото.
   - **Выбор фонов**: возможность сменить фоновые обои для разделов меню.

4. ℹ️ **О приложении** (Фон: *Ночной Горизонт 4K*)
   - Информация о хосте, версии и кнопка перезагрузки портала.

## 📺 Настройка на Smart TV

### 1. Подключение портала (Start Parameter)
В MSX на телевизоре откройте:  
`Settings` → `Start Parameter` → `Setup`

Введите **только ваш адрес хоста**:
```text
<ВАШ_ПРОЕКТ>.vercel.app
```
*(Media Station X автоматически запросит `/msx/start.json`, который сразу откроет главное корневое меню `/menu.json`)*.

### 2. Подключение штатной заставки Media Station X
В MSX откройте:  
`Settings` → `Screensaver` (или `Настройки` → `Заставка`)

Укажите адрес плейлиста заставки:
```text
https://<ВАШ_ПРОЕКТ>.vercel.app/screensaver.json
```
Установите время бездействия (например, 2 или 5 минут). При простое пульта телевизор будет автоматически включать заставку 4K со сменяющимися пейзажами.
