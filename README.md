# MX Station Player — Медиапортал с Виджетами & Заставкой для Media Station X

Медиапортал на **Python (Flask)** для телевизоров Smart TV (Samsung Tizen, LG webOS, Android TV, Apple TV, Fire TV), работающий через оболочку **Media Station X** с поддержкой плееров **MX Player** / встроенного плеера.

---

## 🌟 Ключевые возможности

### 1. Стандартная функция заставки в Media Station X
В самом Media Station X есть встроенный режим заставки (**Настройки → Заставка** / **Settings → Screensaver**):
- **Адрес для заставки**: `http://<IP_СЕРВЕРА>:5000/slideshow.json`
- При срабатывании таймаута бездействия в MSX автоматически запускается слайд-шоу в 4K разрешении со сменяющимися пейзажами, космическими туманностями и ночными городами.
- Также доступен полноэкранный интерактивный веб-режим заставки по адресу `http://<IP_СЕРВЕРА>:5000/screensaver`.

### 2. Полупрозрачные виджеты с эффектом стекла (Glassmorphism & Blur)
На главном экране отображаются стильные полупрозрачные виджеты с регулируемым размытием (`backdrop-filter: blur`):
- **Виджеты часов (3 варианта)**:
  1. *Цифровые Неон (Digital Cyber)* — крупные светящиеся цифры с отображением секунд, анимацией двоеточия и датой.
  2. *Минимал Модерн (Modern Minimal)* — лаконичные утонченные часы с градиентным шрифтом и крупным днем недели.
  3. *Аналоговые часы (Analog Luxury Chrono)* — плавный круглый циферблат с часовой, минутной и непрерывно скользящей секундной стрелкой.
  4. *Режим «Оба стиля часов»* или возможность скрыть часы.
- **Виджеты календаря (3 варианта)**:
  1. *Сетка месяца (Month Grid)* — интерактивный календарь с автоматическим расчетом дней, подсветкой сегодняшней даты и выходных.
  2. *Компактный день (Compact Card)* — крупное число, месяц, день недели и статус дня.
  3. *Планировщик ТВ (Schedule & Events)* — список ближайших трансляций, фильмов и вечернего релакса.

### 3. Свободное размещение виджетов
В настройках интерфейса в один клик можно выбрать, где располагаются виджеты:
- **Посередине** (Center)
- **Слева** (Left)
- **Справа** (Right)
- **Сверху** (Top)
- **Снизу** (Bottom)

### 4. Выбор заднего фона (4K Обои или Градиенты)
- **Готовые 4K фотографии**: Космическая Аврора, Ночной Киберпанк, Горный Закат, Океанский Прибой, Теплый Огонь Камина.
- **Динамические градиенты**: Deep Space (глубокий космос), Neon Sunset (неоновый закат), Emerald Night (изумрудная ночь).
- Настройки синхронизируются с `start.json` и `menu.json` для телевизора.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python app.py
```
Сервер запустится на порту `5000` и будет доступен по локальной сети:
`http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/`

## 📺 Настройка на Smart TV (Media Station X)

### Шаг 1. Ввод Start Parameter (Основной портал)
1. Откройте **Media Station X** на Smart TV.
2. Перейдите в **Settings → Start Parameter → Setup**.
3. Введите адрес:
   ```text
   http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/start.json
   ```
4. Подтвердите выбор. Загрузится главное меню с боковой панелью и постерами.

### Шаг 2. Настройка стандартной заставки Media Station X
1. В MSX откройте **Settings → Screensaver** (или **Настройки → Заставка**).
2. Выберите тип заставки или укажите URL плейлиста слайд-шоу:
   ```text
   http://<IP_ВАШЕГО_КОМПЬЮТЕРА>:5000/slideshow.json
   ```
3. Установите удобное время срабатывания (например, 2 или 5 минут).
4. Теперь при бездействии телевизора MSX будет запускать атмосферную 4K заставку.
