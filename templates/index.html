Инструкция по настройке

01

Установка приложения

Установите приложение Media Station X из официального магазина (Google Play на Android TV / Google TV, Samsung Smart Hub для Tizen, LG Content Store для webOS).

02

Ввод адреса сервера

Запустите MSX на ТВ, откройте Settings → Start Parameter → Setup и введите URL адрес: {{ base_url }}/start.json.

03

Запуск в MX Player

Нажмите кнопку OK на пульте для воспроизведения любого фильма или канала. На устройствах Android TV вы также можете запускать поток через внешний плеер MX Player.
